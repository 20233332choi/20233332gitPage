# GitHub Pages 개인 CV/Resume 포트폴리오 웹페이지 제작 지침

본 문서는 과제 제출용 개인 CV/Resume 기반 포트폴리오 웹페이지 제작의 세부 지침 사항을 정리한 문서입니다.

## 1. 프로젝트 목표
- GitHub Pages를 활용하여 개인 CV/Resume 기반 포트폴리오 웹페이지 제작.
- 자신의 전공, 관심 분야, 기술 역량, 프로젝트 경험, 활동 이력, 이력서 PDF, 연락처 정보를 구조적으로 정리하고 최종 결과물을 GitHub Pages에 배포.
- 제출 시 GitHub Repository 링크와 배포된 GitHub Pages URL을 함께 제출.

## 2. 제출물 명시
- **GitHub Repository URL**: `https://github.com/username/portfolio`
- **GitHub Pages 배포 URL**: `https://username.github.io/portfolio` (또는 사용자 계정 페이지일 경우 `https://username.github.io`)

---

## 3. 페이지 구성 포맷 (Format)

### ① 자기소개 / About Me
- 전공
- 관심 분야
- 진로 목표
- 현재 학습 중인 기술
- AI 분야에서의 관심 주제
- **예시**:
  > 인공지능공학을 전공하며 Computer Vision, Natural Language Processing, Data Analysis에 관심이 있습니다. 향후 AI 서비스 개발자 또는 AI 연구자로 성장하는 것을 목표로 합니다.

### ② Education
- 학교명
- 학과
- 학년
- 재학 기간
- 주요 수강 과목
- GPA / Academic Score 선택 기재
- **예시**:
  * Chosun University
  * Department of Artificial Intelligence Engineering
  * Year: 3rd year
  * Relevant Coursework: Machine Learning, Deep Learning, Data Structures, Web Programming
  * GPA: 4.1 / 4.5 (Optional)

### ③ Skills (숙련도 정보 포함)
- **예시**:
  * Programming: Python (Intermediate), JavaScript (Basic), C/C++ (Basic)
  * AI / ML: PyTorch (Basic), TensorFlow, scikit-learn
  * Web: HTML, CSS, React (Basic)
  * Tools: Git (Basic), GitHub, VS Code, Docker
  * Database: MySQL, SQLite

### ④ Projects
- Summary (한 줄 요약)
- Period (수행 기간)
- Tech Stack (사용 기술)
- Role (본인 역할)
- Key Features (주요 기능)
- Results (결과 또는 성과)
- GitHub (링크)
- Demo / Image (결과 이미지 또는 데모 링크)

### ⑤ Experience
- 포함 가능 항목: 연구실 인턴, 동아리, 공모전, 해커톤, 팀 프로젝트, 수업 조교, 학과 활동, 개인 개발 활동, 오픈소스 기여 경험 등.
- **예시**:
  * AI Lab Undergraduate Intern
  * Programming Club Member
  * Capstone Design Team Project
  * AI Competition Participant

### ⑥ CV / Resume PDF 링크
- 이력서 다운로드 링크 제공 (`[Download My Resume](./resume.pdf)`)
- ⚠️ **주의**: PDF에는 주민등록번호, 주소, 전화번호 등 민감한 개인정보를 포함하지 않아야 함.

### ⑦ Contact
- Email: `student@example.com`
- GitHub: `https://github.com/username`
- LinkedIn: (선택)
- Blog / Notion: (선택)

### ⑧ Career Goal / Future Plan
- AI Developer, Data Scientist, Computer Vision Engineer, Graduate School / Research Track 등 커리어 로드맵 및 향후 계획 기술.
